# GPT Model For Summarizing Any PDF

AI tool to make short summary of long PDF files using Python, Flask, BART Transformer Model & NLP.

## Features
- Upload any PDF
- Get Short / Medium / Long / Detailed Summary
- Saves hours of reading time

## Tech Used
Python, Flask, BART Transformer, NLP, PyPDF2

## How to Run
pip install -r requirements.txt
python app.py
